1 Introduction

Samples collected on the same day of a differentiation experiment can differ in their developmental progression. Bulk RNA-seq measures gene expression across these samples, providing a way to assess their progression relative to a reference time course. This tutorial uses time-dependent gene expression to estimate where each sample falls along that reference.

The tutorial is intended for researchers who have processed bulk RNA-seq data and want to compare differentiation timing across samples or experimental conditions. It explains temporal-gene selection, principal component analysis (PCA), trajectory fitting, and validation using a cardiomyocyte differentiation time course. The code examples assume basic familiarity with R and RNA-seq expression matrices.

The workflow has three stages:

  1. Select genes whose expression changes across the reference time course.
  2. Fit PCA to the mean expression profile at each reference timepoint and connect the resulting points in time order.
  3. Project each sample onto the trajectory.

Each sample receives a predicted reference time, a differentiation score scaled from 0 to 1, and a squared distance from the trajectory. The predicted time and score describe differentiation relative to the selected reference. The distance helps assess how closely the sample resembles the reference at its predicted position.

2 Function inputs

The workflow uses two functions. get_temporal_genes() selects time-dependent genes from raw counts and variance-stabilized (VST) expression in the reference samples. score_differentiation_timing() then uses the selected genes and normalized expression, such as VST expression, to fit the trajectory and score samples.

Both matrices must have genes in rows and samples in columns, with unique gene and sample identifiers. Gene selection requires integer-like, unnormalized counts and a VST matrix with the same gene and sample identifiers. The metadata must contain one row per sample, a sample ID column, and a numeric timepoint column. The default column names are sample_id and day_numeric; use sample_id_col and time_col to specify other names.

By default, the scoring function uses all supplied samples to define the reference. For a study with reference and experimental samples, select temporal genes from the reference cohort and pass its sample IDs through reference_samples when scoring. Both functions require at least two distinct, finite numeric timepoints in the reference. Samples outside the reference can have missing timepoints.

Gene selection requires the Bioconductor packages DESeq2 and edgeR. Install them before running the examples:

install.packages('BiocManager')
BiocManager::install(c('DESeq2', 'edgeR'))

3 Reference dataset

The example uses processed data from NCBI GEO accession GSE122380, a bulk RNA-seq time course of human induced pluripotent stem cell differentiation into cardiomyocytes. The reference contains 192 samples from 13 cell lines collected across differentiation days 1 through 15.

The repository includes sample metadata, a raw gene-count matrix, and a VST expression matrix. These files contain the inputs needed for gene selection and scoring, following read processing, alignment, quantification, and variance-stabilizing transformation.

To follow the example, download or clone the repository and open R in its root directory. Load the data with the supplied loader, which puts both matrices in metadata sample order:

4 Scoring workflow

4.1 Select temporal genes

First, select genes whose expression changes across the reference time course. get_temporal_genes() applies three sequential filters, using raw counts for the expression filter and DESeq2 likelihood-ratio test (LRT), followed by VST expression for the range filter. A gene must pass all three filters to enter the trajectory model.

  1. Expression filter. The function normalizes counts using the trimmed mean of M-values (TMM) method and calculates counts per million (CPM). For each gene, it calculates the mean CPM at each reference timepoint and keeps the gene when its largest timepoint mean reaches the expression threshold.
  2. DESeq2 likelihood-ratio test. The full model includes categorical time and any requested adjustment covariates. The reduced model contains the adjustment covariates without time. Genes with an adjusted LRT p-value below the selected threshold continue to the final filter.
  3. VST-range filter. The function calculates the mean VST expression at each reference timepoint and keeps genes whose range across those means reaches the selected threshold.

The LRT tests whether adding categorical time improves the count model. If the full and reduced models have maximized log likelihoods ell_full and ell_reduced, the likelihood-ratio statistic is

\[ \mathrm{LR} = 2(\ell_\mathrm{full} - \ell_\mathrm{reduced}). \]

Treating time as a categorical factor allows the test to detect nonlinear expression changes across timepoints. For GSE122380, both models include cell_line to account for differences among cell lines. With adjustment_covariates = 'cell_line', the full model is ~ cell_line + day_numeric and the reduced model is ~ cell_line. The function converts day_numeric to a factor for this test. If no adjustment covariates are supplied, the reduced model is the intercept-only model, ~ 1.

source('functions/get_temporal_genes.R')

temporal_selection <- get_temporal_genes(
  raw_counts = counts,
  vst_expression = vst,
  metadata = metadata,
  sample_id_col = 'sample_id',
  time_col = 'day_numeric',
  adjustment_covariates = 'cell_line'
)

temporal_genes <- temporal_selection$temporal_genes

For a dataset containing several experimental groups, use reference_group_col and reference_group_value together to select one group as the reference. These arguments restrict the input to that group before applying the three filters and fitting the DESeq2 models.

The example uses the default thresholds: a maximum day-mean TMM CPM of at least 10, an adjusted LRT p-value below 1e-7, and a day-mean VST range of at least 0.6. 4.2 Fit the PCA reference space

Next, use the selected temporal genes to define the reference PCA space. The scoring function first averages expression across reference samples at each timepoint, then fits PCA to these mean profiles. Each timepoint therefore contributes one profile to the fit, and the resulting trajectory follows the mean expression changes across time.

Let \(\mathbf{x}_i\) be the normalized expression vector for sample \(i\), restricted to the selected temporal genes. For a reference timepoint \(t\), let \(\bar{\mathbf{x}}_t\) be the mean vector across its reference samples:

\[ \bar{\mathbf{x}}_t = \frac{1}{n_t}\sum_{i:\,t_i=t} \mathbf{x}_i. \tag{1} \]

The function centers each gene across the timepoint means and retains its original variance scale when fitting PCA. It keeps the smallest number of principal components (PCs) that together explain at least 99% of the variance between timepoint means. Let \(\boldsymbol{\mu}\) be the mean of those profiles and let \(W\) contain the retained PCA loading vectors. The PCA coordinates for sample \(i\) are

\[ \mathbf{z}_i = (\mathbf{x}_i - \boldsymbol{\mu})W. \tag{2} \]

This transformation places reference and experimental samples in the same reference PCA space. In the GSE122380 fit, seven PCs meet the 99% variance target. The number of retained PCs depends on the reference cohort and the selected temporal genes.

Figure 4. Individual samples projected into centered, unscaled PCA spaces fitted to reference timepoint means. The full temporal-gene set defines the scoring model. The C1+C2 and C3+C4 subsets show how early and late expression patterns contribute to the time-course structure.

PCA loadings identify the genes that contribute most strongly to each axis. Figure 5 labels genes with the largest positive and negative PC1 and PC2 loadings and shows GO enrichment for the strongest PC1 loadings. This analysis helps interpret the expression changes represented by the reference axes.

Figure 5. PCA loading genes and GO enrichment. a-b. The ten largest positive and negative PC1 and PC2 loading genes. Ambiguous Ensembl-to-symbol mappings retain the Ensembl ID. c-d. GO enrichment among the 500 strongest negative and positive PC1 loadings.

The sign of a PCA axis is arbitrary. For readability, PC1 is oriented toward increasing differentiation day in the figures. Distances and timing scores are preserved when an axis is reversed.

4.3 Build and score the reference trajectory

After fitting PCA, the function maps each reference timepoint mean to a centroid in the retained PC space. It connects adjacent centroids in time order to form a trajectory made of finite line segments, also called a polyline. This path can bend across several PCs as expression changes during differentiation.

For one segment, let \(\mathbf{a}\) and \(\mathbf{b}\) be its start and end centroids, and let \(\mathbf{z}\) be a sample’s PCA coordinate. The segment direction is \(\mathbf{v}=\mathbf{b}-\mathbf{a}\). The closest point on the finite segment is

\[ \alpha = \operatorname{clip}_{[0,1]} \left( \frac{\langle \mathbf{z}-\mathbf{a},\mathbf{v}\rangle} {\langle \mathbf{v},\mathbf{v}\rangle} \right), \qquad \mathbf{q}=\mathbf{a}+\alpha\mathbf{v}. \tag{3} \]

Clipping \(\alpha\) to the interval from 0 to 1 keeps the projected point within the segment. The function evaluates every segment and selects the one with the smallest squared distance \(\lVert\mathbf{z}-\mathbf{q}\rVert^2\). It then interpolates time between that segment’s endpoints:

\[ \widehat{t}=t_a+\alpha(t_b-t_a), \qquad s=\frac{\widehat{t}-t_{\min}}{t_{\max}-t_{\min}}. \tag{4} \]

Here, \(t_a\) and \(t_b\) are the segment endpoint times, \(\widehat{t}\) is the predicted time, and \(s\) is the differentiation score. The earliest and latest reference times correspond to scores of 0 and 1. Segment clipping keeps every prediction within this reference time range.

The function omits segments whose endpoints have identical coordinates. If the trajectory folds back near itself, a sample can lie close to several segments with different time assignments. Review the trajectory plot and squared distances when assessing these cases, because a small distance alone may leave the time assignment ambiguous.

5 Leave-one-cell-line-out validation

Leave-one-cell-line-out validation tests how well the reference trajectory predicts differentiation time in a cell line excluded from training. For each cell line, the workflow:

  1. removes that cell line from the training reference;
  2. selects temporal genes using the remaining cell lines;
  3. fits the PCA and centroid trajectory using the remaining cell lines; and
  4. projects the held-out samples onto that fitted trajectory.

Temporal-gene selection, including the count-based DESeq2 LRT, is repeated in every fold. All folds use the supplied VST matrix, since the repository contains the transformed values without the upstream transformation procedure. The results therefore measure transfer to held-out cell lines within this processed cohort, conditional on the shared VST matrix. Assessing transfer to an independently processed study requires a separate validation dataset.

The validation function also labels genes with positive Spearman correlations with time as maturation genes and those with negative correlations as progenitor genes. These labels summarize fold-specific expression patterns. The accuracy results below use the complete temporal-gene set selected in each fold.

source('functions/get_temporal_genes.R')
source('functions/score_differentiation_timing.R')
source('functions/run_loo_maturation.R')

6 Interpreting results

6.1 Read the score and distance together

Use the sample-level timing_fit$scores table to read the result:

  • predicted_time gives the sample’s position on the original reference-time scale.
  • differentiation_score rescales that position so the earliest and latest reference times are 0 and 1.
  • squared_distance measures how close the sample is to its nearest trajectory segment in the retained PCA space.

Interpret the score in relation to the reference timepoints. A score of 0.5 places the predicted time halfway between the earliest and latest reference times. In this day 1 to day 15 reference, it corresponds to a predicted day of 8. The biological meaning of that position depends on the differentiation process and the stages represented in the reference.

Read squared_distance alongside the score. A sample with a large distance has an expression profile that fits the reference path poorly, even though the function assigns it a predicted time. Compare its distance with those of reference samples and consider possible differences in cell composition, experimental conditions, or batch before drawing a biological conclusion.

6.2 Apply the method to another study

Choose reference samples with known timepoints that span the differentiation stages relevant to the study. Select temporal genes from those reference samples, then use the same reference to fit PCA and the trajectory. Keeping experimental samples out of both fitting steps allows their scores to be interpreted relative to the reference.

For example, if metadata for your own study identifies samples as reference in a group column, the code below selects genes from that group and scores every sample. Here, counts, vst, and metadata are your study’s aligned inputs, with sample_id and day_numeric columns in the metadata. The scoring matrix contains both reference and experimental samples:

temporal_selection <- get_temporal_genes(
  raw_counts = counts,
  vst_expression = vst,
  metadata = metadata,
  reference_group_col = 'group',
  reference_group_value = 'reference'
)

timing_fit <- score_differentiation_timing(
  expression_matrix = vst,
  metadata = metadata,
  temporal_genes = temporal_selection$temporal_genes,
  reference_samples = temporal_selection$reference_samples
)

Experimental samples can have missing timepoints when the group arguments above identify the reference samples with known times. Alternatively, subset the inputs to reference samples for gene selection, then pass the combined expression matrix and metadata to the scorer with the selected reference IDs. Include relevant adjustment covariates in gene selection when the reference design supports them.

Before comparing scores, check that gene and sample identifiers match across inputs and that reference and experimental expression values use compatible normalization. Compare scores within a shared reference model and review experimental-sample distances against the reference distances. If the biological process or batch structure differs substantially, choose a suitable reference and validate prediction in that setting.
