1 Introduction

Differentiation timing is estimated by projecting bulk RNA-seq samples onto a reference trajectory in principal component analysis (PCA) space. PCA is fitted to the mean expression of temporal genes at each reference timepoint, and the resulting centroids are connected in time order. Each sample’s position on the trajectory gives a predicted reference time and a differentiation score from 0 to 1. The projection distance measures fit to the reference.

The analysis uses a cardiomyocyte differentiation time course from GSE122380, with leave-one-cell-line-out validation to assess prediction across cell lines.

2 Function inputs

get_temporal_genes() requires integer-like raw counts and variance-stabilized (VST) expression with matching gene and sample identifiers. score_differentiation_timing() uses normalized expression and the selected temporal genes. In both matrices, rows are genes and columns are samples. Row and column names must be unique, with one metadata row per sample.

The default metadata columns are sample_id and day_numeric; other names can be specified through sample_id_col and time_col. The reference must span at least two distinct, finite numeric timepoints. Non-reference samples can have missing timepoints.

The scorer uses all supplied samples as the reference unless reference_samples specifies a subset. For comparisons across experimental conditions, gene selection and trajectory fitting are restricted to the reference cohort.

Gene selection requires DESeq2 and edgeR:

install.packages('BiocManager')
BiocManager::install(c('DESeq2', 'edgeR'))

GSE122380 contains 192 bulk RNA-seq samples from 13 human induced pluripotent stem cell lines collected over days 1 through 15 of cardiomyocyte differentiation. The metadata, raw counts, and VST expression are included in the repository.

4 Scoring workflow

4.1 Temporal-gene selection

get_temporal_genes() applies three sequential filters within the reference cohort. Raw counts are used for the expression filter and DESeq2 likelihood-ratio test (LRT), and VST expression is used for the range filter. The trajectory model includes genes that pass all three:

  1. Expression filter. Counts are normalized by the trimmed mean of M-values (TMM) method and expressed as counts per million (CPM). Genes are retained if their highest mean CPM across reference timepoints reaches the expression threshold.
  2. DESeq2 likelihood-ratio test. The full model includes categorical time and any requested adjustment covariates. The reduced model contains the adjustment covariates without time. Genes with an adjusted LRT p-value below the selected threshold continue to the final filter.
  3. VST-range filter. Genes are retained if the range of their mean VST expression across reference timepoints reaches the selected threshold.

The LRT tests whether adding categorical time improves the count model. If the full and reduced models have maximized log likelihoods ell_full and ell_reduced, the likelihood-ratio statistic is

\[ \mathrm{LR} = 2(\ell_\mathrm{full} - \ell_\mathrm{reduced}). \]

For GSE122380, the full model is ~ cell_line + day_numeric and the reduced model is ~ cell_line. Time is converted to a categorical factor, allowing nonlinear expression changes across days. Including cell_line in both models accounts for differences among cell lines. With no adjustment covariates, the reduced model is ~ 1.

source('functions/get_temporal_genes.R')

temporal_selection <- get_temporal_genes(
  raw_counts = counts,
  vst_expression = vst,
  metadata = metadata,
  sample_id_col = 'sample_id',
  time_col = 'day_numeric',
  adjustment_covariates = 'cell_line'
)

temporal_genes <- temporal_selection$temporal_genes

reference_group_col and reference_group_value restrict all three filters to a specified group of reference samples.

The default thresholds are a maximum day-mean TMM CPM of at least 10, an adjusted LRT p-value below 1e-7, and a day-mean VST range of at least 0.6. 4.2 Reference PCA

The reference PCA is fitted to mean temporal-gene expression at each timepoint. Each timepoint contributes one expression profile to the fit, regardless of its sample count.

Let \(\mathbf{x}_i\) be the normalized expression vector for sample \(i\), restricted to the selected temporal genes. For a reference timepoint \(t\), let \(\bar{\mathbf{x}}_t\) be the mean vector across its reference samples:

\[ \bar{\mathbf{x}}_t = \frac{1}{n_t}\sum_{i:\,t_i=t} \mathbf{x}_i. \tag{1} \]

PCA is centered without variance scaling. The smallest number of principal components (PCs) explaining at least 99% of the variance between timepoint means is retained. With \(\boldsymbol{\mu}\) denoting the mean of those profiles and \(W\) the retained loading vectors, the PCA coordinates for sample \(i\) are

\[ \mathbf{z}_i = (\mathbf{x}_i - \boldsymbol{\mu})W. \tag{2} \]

Reference and experimental samples are projected using the same centering and loadings. Seven PCs meet the 99% variance target in GSE122380; the retained number depends on the reference cohort and temporal-gene set.

4.3 Trajectory fitting and sample projection

The reference timepoint means define centroids in the retained PCA space. Connecting adjacent centroids in time order produces a polyline trajectory that can bend across multiple PCs.

For one segment, let \(\mathbf{a}\) and \(\mathbf{b}\) be its start and end centroids, and let \(\mathbf{z}\) be a sample’s PCA coordinate. The segment direction is \(\mathbf{v}=\mathbf{b}-\mathbf{a}\). The closest point on the finite segment is

\[ \alpha = \operatorname{clip}_{[0,1]} \left( \frac{\langle \mathbf{z}-\mathbf{a},\mathbf{v}\rangle} {\langle \mathbf{v},\mathbf{v}\rangle} \right), \qquad \mathbf{q}=\mathbf{a}+\alpha\mathbf{v}. \tag{3} \]

The projection is clipped to each finite segment by constraining \(\alpha\) between 0 and 1. The segment minimizing \(\lVert\mathbf{z}-\mathbf{q}\rVert^2\) determines the sample’s assignment, and its endpoint times are used to interpolate predicted time:

\[ \widehat{t}=t_a+\alpha(t_b-t_a), \qquad s=\frac{\widehat{t}-t_{\min}}{t_{\max}-t_{\min}}. \tag{4} \]

Here, \(t_a\) and \(t_b\) are the segment endpoint times, \(\widehat{t}\) is predicted time, and \(s\) is the differentiation score. Scores are bounded between 0 and 1, corresponding to the earliest and latest reference times.

Zero-length segments are omitted. If the trajectory folds back near itself, nearby segments can yield ambiguous time assignments even when projection distances are small.

5 Leave-one-cell-line-out validation

Each cell line is held out in turn. Temporal-gene selection, including the DESeq2 LRT, and PCA trajectory fitting are repeated using the remaining cell lines. The held-out samples are then projected onto that fold’s reference trajectory.

All folds share the supplied VST matrix because the upstream transformation procedure is unavailable in the repository. Validation therefore assesses transfer across cell lines within this processed cohort, conditional on the shared transformation. Transfer to an independently processed study requires separate validation.

Within each fold, genes with positive and negative Spearman correlations with time are labeled maturation and progenitor genes, respectively. Reported accuracy uses the complete temporal-gene set selected in that fold.

source('functions/get_temporal_genes.R')
source('functions/score_differentiation_timing.R')

6 Interpreting results

6.1 Scores and projection distances

timing_fit$scores contains the sample-level estimates:

  • predicted_time gives the sample’s position on the original reference-time scale.
  • differentiation_score rescales that position so the earliest and latest reference times are 0 and 1.
  • squared_distance measures how close the sample is to its nearest trajectory segment in the retained PCA space.

Scores are specific to the reference lineage, differentiation protocol, and sampled time range. Comparisons across conditions require a shared reference model.

A large projection distance relative to reference samples indicates poor fit to the trajectory and limits the interpretation of predicted time. Differences in cell composition, treatment response, or batch can produce these deviations.

6.2 Reference selection for another study

For comparisons across conditions, temporal-gene selection and trajectory fitting use an independent reference group. The following example identifies that group through a metadata column named group, with reference samples labeled reference. Here, counts, vst, and metadata contain aligned reference and experimental samples from the new study, with the same sample_id and day_numeric columns used above:

temporal_selection <- get_temporal_genes(
  raw_counts = counts,
  vst_expression = vst,
  metadata = metadata,
  reference_group_col = 'group',
  reference_group_value = 'reference'
)

timing_fit <- score_differentiation_timing(
  expression_matrix = vst,
  metadata = metadata,
  temporal_genes = temporal_selection$temporal_genes,
  reference_samples = temporal_selection$reference_samples
)

Experimental samples can have missing timepoints. Adjustment covariates can be included in gene selection when supported by the reference design.

The reference should span the relevant differentiation stages and use gene identifiers and normalization compatible with the experimental samples. Differences in protocol, cell composition, or batch can alter scores and projection distances. Application to a substantially different dataset requires validation in that setting.
